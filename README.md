# Sistema_de_Biblioteca_em_C

## O que o programa faz:
O sistema de biblioteca,desenvolvido por mim em na linguagem de programação C, é um sistema onde o usuário(dono da biblioteca) registra a quantidade de livros que irá cadastrar na biblioteca e os livros pelo nome da obra e autor.Além disso, o usuário também registra no sistema os dados dos clientes e o preço dos livros cadastrados,podendo buscar o livro cadastrado no sistema através do código ou nome do autor ou nome do autor do livro de acordo com a opção escolhida pelo usuário e o sistema mostra os livros mais caros e mais baratos. As opções do sistema são os seguintes:

#### 1 - Listar todos os livros
#### 2 - Quantidade de livros acima de R$ 80,00
#### 3 - Buscar livro por Codigo
#### 4 - Buscar livros por Autor
#### 5 - Ver livro mais Caro e mais Barato
#### 6 - Ver Clientes Cadastrados
#### 0 - Sair do sistema.
